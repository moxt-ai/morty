# macOS/Linux POSIX-shell setup reference

Download artifact: {{BASE_URL}}/setup.mjs

Use the selected Agent and Node from the original workspace. These commands work
in bash/zsh, including Linux inside WSL. They are not PowerShell commands.

```sh
set -eu
BASE_URL="{{BASE_URL}}"
WORKSPACE="$PWD"
npm install --global @moxt-ai/mobius@latest
SCRIPT_DIR="$(mktemp -d "${TMPDIR:-/tmp}/morty-setup.XXXXXX")"
SCRIPT="$SCRIPT_DIR/setup.mjs"
HTTP_STATUS="$(curl --fail --show-error --silent --connect-timeout 10 --max-time 45 --max-redirs 0 "$BASE_URL/setup.mjs" --output "$SCRIPT" --write-out '%{http_code}')"
[ "$HTTP_STATUS" = 200 ] || { printf '%s\n' "Setup download failed or redirected" >&2; exit 1; }
chmod 600 "$SCRIPT"
cat "$SCRIPT"
```

Stop on an install/download error. Do not enable redirect following. Inspect the
script before execution. Use
`node "$SCRIPT" setup --base-url "$BASE_URL" --cwd "$WORKSPACE" --harness "$HARNESS" --session-id "$SESSION_ID"`
with your own harness ID and exact current session ID. For pairing, use
`node "$SCRIPT" pair --base-url "$BASE_URL" --cwd "$WORKSPACE" --token="$TOKEN" --harness "$HARNESS"`.
Assign values before expanding them; command-scoped assignments do not affect
expansion on the same line. Do not set Documents yourself unless setup reports
`DOCUMENT_DIR_REQUIRED`; macOS uses its Documents folder, Linux uses `xdg-user-dir`.
