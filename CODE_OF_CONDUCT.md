# Code of Conduct

Morty welcomes contributors with different backgrounds and levels of experience.
Be respectful, give constructive feedback about the work, and make room for others
to participate. Disagreement is welcome; harassment, threats, discriminatory
remarks, sexual harassment and publishing private information are not.

These expectations apply in project issues, pull requests and other project spaces,
and when representing the project publicly. Maintainers may edit or remove harmful
content, close discussions, or restrict participation when needed to protect the
community. They should consider the impact and context, explain their decision to
the affected person privately when practical, and avoid disclosing a reporter's
identity without consent.

Report conduct concerns privately to [acmerfight@gmail.com](mailto:acmerfight@gmail.com).
Include links and relevant context without sharing unnecessary personal data.
Contact the same address to request reconsideration of a moderation decision.
For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
